# QR Code Instructions

Use these steps after the site is published.

1. Copy the final GitHub Pages URL.
2. Paste it into a QR code generator approved by your organization.
3. Download the QR code as an image.
4. Test it with iPhone and Android cameras.
5. Print a small proof before ordering signs or banners.
6. Place the QR code near the words: `Scan to explore Fruit Heights America 250 founding documents`.

Helpful print tips:

- Keep strong contrast: dark QR code on a light background.
- Leave white space around the code.
- Use a short URL if possible.
- Test from the same distance visitors will scan at the event.
